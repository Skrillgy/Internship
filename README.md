# NavalBattle Service

REST-сервис для игры в морской бой.

На текущем этапе базовый каркас проекта:

- FastAPI-приложение;
- PostgreSQL;
- SQLAlchemy;
- Alembic;
- Docker Compose;
- первая миграция базы данных;
- ручка "POST /games";
- интеграционные тесты.

## Стек

- Python 3.12
- FastAPI
- Uvicorn
- PostgreSQL 16
- SQLAlchemy 2
- Alembic
- Pytest
- Docker Compose

## Start

```bash
docker compose up --build -d
